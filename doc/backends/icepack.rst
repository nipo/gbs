icepack Backend
===============

The icepack backend converts ASCII bitstreams to binary bitstreams for Lattice iCE40 FPGAs.

Overview
--------

icepack is a utility from the IceStorm project that packs ASCII bitstream files (``.asc``) generated by nextpnr into binary bitstream files (``.bin``) suitable for programming to iCE40 FPGAs.

Supported Inputs
----------------

- ``ice40-asc``: ASCII bitstream file from nextpnr-ice40

Supported Outputs
-----------------

- ``ice40-bin``: Binary bitstream file
- ``ice40-bitstream``: Alias for binary bitstream

Configuration
-------------

Tool Configuration
~~~~~~~~~~~~~~~~~~

In ``.gbs.yaml``:

.. code-block:: yaml

   tools:
     - name: icepack
       config:
         executable: icepack  # Path to icepack binary

Backend Configuration
~~~~~~~~~~~~~~~~~~~~~

In project file (minimal configuration needed):

.. code-block:: yaml

   backend_config:
     icepack:
       icepack_tool: icepack  # Tool identifier for lookup (optional)

Example Project
---------------

.. code-block:: yaml

   name: ice40_design
   root_library_name: work

   output_groups:
     - name: bitstream
       topcell: top_module
       target:
         part: up5k
         package: sg48
       outputs:
         - type: ice40-bitstream
           path: build/design.bin

   root_partition_template:
     dependencies:
       - library.partition

When you request ``ice40-bitstream`` or ``ice40-bin`` output, GBS automatically runs the complete toolchain: Yosys → nextpnr → icepack.

Workflow Integration
--------------------

icepack is the final step in the iCE40 open-source toolchain:

.. code-block:: text

   VHDL/Verilog → Yosys → JSON netlist → nextpnr → ASC → icepack → BIN

The binary bitstream can be programmed to the FPGA using tools like:

- ``iceprog``: USB programmer (for iCEstick, iCEBreaker, etc.)
- ``tinyprog``: TinyFPGA programmer
- ``dfu-util``: DFU-based programmers
- Vendor-specific programming tools

Programming Example
-------------------

After building with GBS:

.. code-block:: bash

   # Build the bitstream
   gbs project build

   # Program to FPGA using iceprog
   iceprog build/design.bin

   # Or using tinyprog (TinyFPGA)
   tinyprog -p build/design.bin

Filter Variables
----------------

The icepack backend contributes the following filter variables:

- ``target-usage``: Set to ``bitstream``
- ``target``: Set to ``ice40``

Output File Types
-----------------

The backend supports multiple output type aliases for binary bitstreams:

- ``ice40-bin``: Explicit binary bitstream
- ``ice40-bitstream``: Preferred alias
- ``bitstream``: Generic bitstream type

All three types produce the same binary output format.

Bitstream Format
----------------

The binary bitstream file (``.bin``) contains:

- Configuration bits for FPGA logic elements
- Routing configuration
- I/O configuration
- Block RAM initialization data
- Clock configuration

The file is ready for direct programming to the FPGA's configuration memory.

Requirements
------------

- icepack installed and in PATH (part of IceStorm tools)
- Input ASCII bitstream from nextpnr-ice40
- Compatible with all iCE40 device families

Installation
------------

icepack is part of the IceStorm tools:

.. code-block:: bash

   # From source
   git clone https://github.com/YosysHQ/icestorm.git
   cd icestorm
   make -j$(nproc)
   sudo make install

   # Or use OSS CAD Suite (includes all tools)
   # Download from https://github.com/YosysHQ/oss-cad-suite-build
