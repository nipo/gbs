nextpnr Backend
===============

The nextpnr backend provides FPGA place-and-route using the nextpnr open-source PnR tool.

Overview
--------

nextpnr is a portable FPGA place-and-route tool supporting multiple FPGA architectures. GBS uses nextpnr to place and route synthesized netlists generated by Yosys, with built-in support for Lattice iCE40 devices.

Supported Inputs
----------------

- ``ice40-netlist-json``: Yosys-generated JSON netlist for iCE40
- ``ice40-pcf``: Physical Constraints File for pin assignments (optional)

Supported Outputs
-----------------

- ``ice40-asc``: ASCII bitstream file for iCE40 FPGAs
- ``nextpnr-pnr-report``: Place-and-route report (timing, routing statistics)

FPGA Targets
------------

Currently Supported:
~~~~~~~~~~~~~~~~~~~~

**Lattice iCE40**
  - Pass: ``nextpnr-ice40``
  - Tool: ``nextpnr-ice40``
  - Input: JSON netlist from Yosys
  - Output: ASCII bitstream (``.asc``)

Configuration
-------------

Tool Configuration
~~~~~~~~~~~~~~~~~~

In ``.gbs.yaml``:

.. code-block:: yaml

   tools:
     - name: nextpnr-ice40
       config:
         executable: nextpnr-ice40  # Path to nextpnr-ice40 binary

Backend Configuration
~~~~~~~~~~~~~~~~~~~~~

In project file, specify device in the output group:

.. code-block:: yaml

   backend_config:
     nextpnr:
       tool: nextpnr-ice40          # Tool identifier for lookup

   output_groups:
     - name: bitstream
       topcell: top_module
       target:
         part: hx1k          # iCE40 device (e.g., hx1k, up5k, lp8k)
         package: tq144      # Package type (e.g., tq144, sg48, cm81)
       outputs:
         - type: ice40-asc
           path: build/design.asc

Example Project
---------------

.. code-block:: yaml

   name: ice40_design
   root_library_name: work

   backend_config:
     yosys:
       vhdl_standard: "2008"
     nextpnr:
       tool: nextpnr-ice40

   output_groups:
     - name: bitstream
       topcell: top_module
       target:
         part: up5k          # iCE40 UltraPlus 5K
         package: sg48       # SG48 package
       outputs:
         - type: ice40-asc
           path: build/design.asc

   root_partition_template:
     dependencies:
       - library.partition

Common iCE40 Devices
--------------------

**iCE40 LP/HX Series:**
  - ``hx1k``: 1280 LCs, 64 Kbit RAM
  - ``hx8k``: 7680 LCs, 128 Kbit RAM
  - ``lp384``: 384 LCs, 8 Kbit RAM
  - ``lp1k``: 1280 LCs, 16 Kbit RAM
  - ``lp8k``: 7680 LCs, 128 Kbit RAM

**iCE40 UltraPlus:**
  - ``up5k``: 5280 LCs, 1 Mbit SPRAM, 120 Kbit DPRAM, DSP blocks

**Common Packages:**
  - ``tq144``: 144-pin TQFP
  - ``sg48``: 48-pin QFN
  - ``cm81``: 81-ball csBGA
  - ``cb132``: 132-ball csBGA

Physical Constraints
--------------------

Pin assignments are specified using PCF (Physical Constraints File) format:

.. code-block:: text

   # PCF file example
   set_io led_o 99      # Pin 99: LED output
   set_io clk_i 21      # Pin 21: Clock input
   set_io reset_n 78    # Pin 78: Reset (active low)

Add PCF files to your project as ``ice40-pcf`` file type:

.. code-block:: yaml

   partition_templates:
     - name: constraints
       sources:
         - path: pins.pcf
           file_type: ice40-pcf

Filter Variables
----------------

The nextpnr backend contributes the following filter variables:

- ``target-usage``: Set to ``pnr`` (place-and-route)
- ``target``: Set to ``ice40``

Workflow Integration
--------------------

nextpnr is typically used as part of a complete iCE40 toolchain:

.. code-block:: text

   VHDL/Verilog → Yosys (synth_ice40) → JSON netlist → nextpnr-ice40 → ASC → icepack → BIN

The complete flow in a GBS project:

.. code-block:: yaml

   output_groups:
     - name: bitstream
       topcell: top
       target:
         part: up5k
         package: sg48
       outputs:
         - type: ice40-bitstream  # Final binary bitstream
           path: build/design.bin

GBS automatically chains:

1. Yosys: Synthesis to JSON netlist
2. nextpnr: Place-and-route to ASCII bitstream
3. icepack: Pack to binary bitstream

Requirements
------------

- nextpnr-ice40 installed and in PATH
- Yosys for synthesis (generates JSON netlist input)
- icepack for bitstream packing (optional, for binary output)
- iCE40 device database (included with nextpnr)
